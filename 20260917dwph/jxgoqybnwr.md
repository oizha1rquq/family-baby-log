# 【养生】一碗陈皮药膳粥，健脾祛湿养胃！便宜有效，值得一试！

> 更新时间：2026-09-17 (UTC+8)

《本草纲目》中记载：“橘皮苦能泄能燥，辛能散能和，其治百病，总是取其理气燥湿之功。同补药则补，同泻药则泻，同升药则升，同降药则降。”

        由此可见，陈皮是一种适用性很广的中药。其不但可以做成方剂治疗百病，还能做成药膳，调理人体消化功能。

**行气健脾陈皮粥**

材料：陈皮10克，大米50克。

做法：1. 陈皮浸泡，洗净，撕成小片（比刀切味更佳），用1.5碗清水泡其半小时，然后用大火煎，煮开后改小火煎成大半碗，取出，再加水1.5碗煎成另一半碗，把两次煎好的陈皮汁相兑待用。

          2. 大米淘净，放入锅中，加入陈皮汁及适量清水，煮为稀粥服食，每日1剂。

功效：行气健脾，化痰止咳。适于脾胃气滞，消化不良，脘腹胀满，食欲不振，恶心呕吐，咳嗽痰多，胸膈满闷等。

**健脾消积鸡内金陈皮粉粥**

       材料：陈皮3克，鸡内金5克，砂仁2克，大米30克，白糖少许。

       做法：

       1. 将诸药共研细末；大米淘净，加清水适量煮粥。

       2. 待粥将熟时调入药末及白糖，煮至熟透服食，每日2次，中晚各服1碗。

       功效：健脾消积，适于小儿饮食不节所致的肚腹胀大，面黄肌瘦，呕吐，大便粘滞不爽等。

**除湿祛痰砂仁陈皮鲫鱼汤**

材料：砂仁6克，陈皮1/4个，鲫鱼300～400克，芫荽4棵，生姜3片。

做法：

1. 砂仁打碎；陈皮浸泡去瓤；芫荽洗净。

2. 鲫鱼宰净，去鳞，置油锅慢火煎至两边微黄。

3. 先把陈皮与生姜放进瓦煲内，加入清水2500毫升(约10碗水量)，武火煲沸后加入鲫鱼，滚后改为文火煲2小时。

4. 加入砂仁稍滚，调入适量芫荽及食盐和生油便可。此量可供3～4人用。

功效：温中健脾、除湿祛痰。“春眠不觉晓”，早春人们容易“春困”，宜多喝砂仁陈皮煲鲫鱼汤。

**理气滋阴陈皮老鸭汤**

材料：老鸭一只、陈皮5克、红枣8个，姜3片、米酒1汤匙、盐适量。

做法：

1. 鸭肉洗净，剥皮，斩块，氽水捞起。

2. 红枣洗净，拍扁去核；陈皮用水浸软，刮去白瓤。

3. 煮沸瓦煲里的清水，放入鸭肉、陈皮、红枣、姜片和米酒，武火煮沸，转小火煲一个半小时，下盐调味即可食用。

功效：理气健脾，滋阴补血。陈皮老鸭汤是一道色香味俱全的汉族传统名菜，属于粤菜系。陈皮搭配滋阴补血的老鸭煲汤，取陈皮之弱温性，更增滋补之效。

值得注意的是，专家表示，陈皮药性因其行气燥湿之功，气虚阴虚者如有口干舌燥、干咳无痰；或有胃火者如牙痛、口臭、便秘等，不宜多食陈皮。
